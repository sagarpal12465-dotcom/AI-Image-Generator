# 🎨 AI Image Generator

A desktop application built with Python and Tkinter that generates images from text descriptions using the Pollinations AI API.

## ✨ Features
- 🖼️ **Text-to-Image Generation**: Generate high-quality AI images based on prompt descriptions.
- 💾 **Save As Option**: Easily save generated images to your desired location on your computer.
- 🎨 **User-Friendly GUI**: Clean and modern dark-themed user interface using Tkinter.

## 🚀 How to Run the Project

### Prerequisites
Make sure you have Python installed on your system. You also need the `Pillow` library for image handling.
